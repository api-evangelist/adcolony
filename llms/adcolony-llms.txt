# AdColony

> AdColony was a mobile advertising and app-monetization company known for its
> Instant-Play HD video and interactive Aurora playable ad formats, its iOS and
> Android publisher SDKs, and its V4VC virtual-currency reward system. AdColony was
> acquired by Digital Turbine in 2021 and merged into the DT Exchange. The brand is
> retired: adcolony.com redirects to digitalturbine.com, every developer host is
> gone, and both mobile SDKs are frozen at 2022-06-07 with the iOS repository
> archived and marked deprecated.

**Status: deprecated / absorbed.** Do not integrate. New monetization integrations
should target Digital Turbine (DT Exchange / DT FairBid) at
https://www.digitalturbine.com/app-developers/#monetizationsolutions.

This file is GENERATED by API Evangelist from the AdColony profile at
https://github.com/api-evangelist/adcolony — AdColony never published an llms.txt
(https://www.adcolony.com/llms.txt returns 404 after redirect). It records what of
AdColony's developer surface is still fetchable, and what is not.

## What AdColony published

- **Mobile ads SDKs** — iOS (CocoaPods `AdColony`, last 4.9.0, 2022-06-07) and
  Android (Maven Central `com.adcolony:sdk`, source last 4.8.0, 2022-06-07).
  Integration is authenticated with an App ID and Zone IDs from the AdColony
  Control Panel; there is no developer-callable HTTP API key or OAuth flow.
- **V4VC server-side reward callback** — the one real server-to-server contract.
  AdColony GETs a publisher-hosted URL with `id`, `uid`, `zone`, `amount`,
  `currency`, `verifier` and optionally `custom_id`, authenticated by an MD5 hash of
  those values concatenated with a shared secret. The publisher answers with a bare
  `vc_success`, `vc_decline` or `vc_noreward`; anything else causes AdColony to
  retry, so the publisher must deduplicate on the transaction `id`.
- **Privacy consent APIs** — AdColonyAppOptions carries GDPR and CCPA applicability
  flags plus IAB TCF v1.1/v2.0 consent strings and the IAB US Privacy String,
  propagated to downstream demand.
- **Publisher Reporting API v2.3** — an HTTP reporting API documented ONLY as a PDF
  on support.adcolony.com. That host no longer accepts connections; the reference is
  unrecoverable and no machine-readable spec was ever published.

## What AdColony never published

No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema, Postman collection, MCP server,
A2A agent card, `/.well-known` document, security.txt, status page, SLA, list
pricing, or published rate limits. There is no `Sunset` or `Deprecation` header —
the end-of-life is communicated by README prose and a site-wide redirect.
